# Plan: 优化 Email Center 与模板编辑

## 目标
让邮件中心里的模板真正可维护：管理员/运营可以新建、编辑、复制、启用/停用邮件模板，并且邮件中心会实时使用最新模板内容。

## 改动范围
1. **模板管理页**
   - 增加“新建模板”“编辑模板”“复制模板”入口。
   - 提供表单字段：模板名称、分类、状态、主题、正文、变量列表。
   - 保存后刷新模板列表，并保留当前选中模板。
   - 显示明确错误提示，不再把所有失败都显示成无权限。

2. **邮件中心体验**
   - 模板选择仍用于生成邮件预览。
   - 模板编辑后，邮件中心读取最新模板。
   - 保留现有选择 case、自动填充变量、保存草稿、打开 Outlook 的流程。

3. **后端权限与数据写入**
   - 新增保存模板的服务端函数。
   - 仅允许 Admin / Operator 管理模板。
   - 通过数据库策略允许已授权角色写入 `email_templates`。
   - 记录模板创建/更新审计日志。

4. **样式与中文文案**
   - 增加模板编辑表单所需样式。
   - 补齐新增中文翻译。

## 验证
- 管理员账号能打开模板管理页。
- 管理员能编辑已有模板并保存。
- 新建/复制模板后，Email Center 能选择并使用新内容。
- 非管理员/非运营保存时返回权限错误。
- 构建日志无错误。

## 技术细节
- 修改 `workbench.functions.ts` / `workbench.server.ts` 添加 `saveTemplate`。
- 修改 `templates.tsx` 实现编辑 UI。
- 视需要添加数据库迁移，为模板表补齐 authenticated 写权限与 RLS 策略。
